NUMBER GUESSING GAME

Task 2 - Number Guessing Game

Description:
This project is a simple number guessing game developed using Java.

The computer generates a random number between 1 and 100. The user has 7 attempts to guess the number. After every guess, the program tells the user whether the entered number is too high or too low.

If the user guesses the correct number, the game displays the number of attempts taken. If all 7 attempts are used, the game displays the correct number and shows "You Lost!".

The user can also choose to play another round after completing a game.

Technologies Used:

* Java

Concepts Used:

* Scanner
* Random
* Variables
* while loop
* if-else statements
* break statement

Project File:
NumberGuessingGame.java

How to Run:

1. Open the project folder in VS Code.
2. Open the terminal.
3. Compile the program:

javac NumberGuessingGame.java

4. Run the program:

java NumberGuessingGame

Sample Output:

Round 1
Guess a number between 1 and 100

Enter your guess: 50
Too Low!

Enter your guess: 75
Too High!

Enter your guess: 63
Correct!

You guessed it in 3 attempts.
